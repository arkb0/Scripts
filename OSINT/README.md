# Security & OSINT Toolset

A collection of Python-based utilities for Open Source Intelligence (OSINT), network auditing, and data processing.

## Tools Overview

* **BreachNotifier**: Cross-references accounts with Have I Been Pwned (HIBP) to identify exposed services.
* **CheckUsername**: Automates searches across various social media platforms and web services to verify the existence of specific usernames.
* **EXIF**: Extracts metadata from image files and includes a CSV deduplication utility for managing large datasets.
* **PortScan**: A multi-threaded port scanner designed to identify open ports and services on a target host.
* **WhoIs**: A domain reconnaissance script that retrieves fundamental WHOIS ownership data and resolves common DNS records.
